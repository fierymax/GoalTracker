# GoalTracker 目标追踪（魔兽世界正式服插件）v1.0.1

**一个战网账号全局的 7,000,000 金币目标追踪器。**
统计你账号下**所有角色的金币 + 战团银行金币**，每攒够目标的 **0.01%（默认 = 700 金）** 就在屏幕中央用大字号播报一句鼓励：

> 干得漂亮，您获得了 700 金币，您离目标还有 99.99%

没有进度条，没有小地图按钮，界面上只有一行你说了算的文字。

---

## 一、安装

1. 解压得到文件夹 `GoalTracker`，复制到：

   ```
   ...\World of Warcraft\_retail_\Interface\AddOns\
   ```

   最终应为：`...\_retail_\Interface\AddOns\GoalTracker\GoalTracker.toc`

2. 彻底退出游戏再进（改动插件必须完全重启客户端）。
3. 角色选择界面左下角「插件」里确认已勾选。**若提示"插件已过期"**：勾选"加载过期插件"，或把 `GoalTracker.toc` 第一行的 `## Interface: 120100` 改成你客户端的版本号——进游戏输入 `/dump select(4, GetBuildInfo())` 回车，聊天框显示的数字就是当前版本号。

## 二、账号金币是怎么统计的

```
账号总金币 = 当前角色实时金币
           + 其它已记录角色的金币（上次登录时的快照）
           + 战团银行（Warband Bank）已存入金币
```

- **当前角色**：实时读取，分秒不差。
- **其它角色**：暴雪没有提供"直接读取同账号其他角色金币"的接口，所以插件会在**每个角色登录/下线时自动记录一次金币快照**。换句话说：**登录过的角色才会被统计进去**，想让某个角色计入总数，用它登录一次即可（记录后就一直生效）。
- **战团银行**：打开战团银行时自动刷新，另外每 45 秒也会尝试刷新一次。战团银行的钱是账号共享的，只计一次，不会重复。
- 设置面板里有「账号金币统计」区块，列出每个角色的金币、战团银行和合计，可点「刷新」手动更新，或「清除角色记录」重新统计。
- 也可以直接在聊天框输入 **`/gt gold`** 打印明细。
- 鼠标悬停在屏幕上的显示框，同样会弹出逐角色的明细。

> 想只看当前角色？把「统计范围」改成「仅当前角色」即可。

## 三、里程碑播报

| 项目 | 说明 |
| --- | --- |
| 触发条件 | 进度每跨过 **0.01%** 的整数倍播报一次（7,000,000 × 0.01% = **700 金**） |
| 播报内容 | `{praise}，您获得了 {gain} 金币，您离目标还有 {remain}` |
| 位置 | 屏幕正中，大字号 + 粗描边 + 阴影，淡入 → 上浮 → 淡出 |
| 鼓励语 | 内置 **50 句**随机（25 句通用 + 25 句搞钱/网络梗），不重复上一句 |

播报文本可自己改，占位符：

| 占位符 | 含义 |
| --- | --- |
| `{praise}` | 随机鼓励语 |
| `{gain}` | 本次获得的金币（本次快照与上次之间的增量） |
| `{remain}` | 距离目标还差百分之多少（**自带 `%`**，模板里不要再写 `%`） |
| `{pct}` | 当前已完成百分比（**自带 `%`**） |
| `{cur}` / `{goal}` | 当前值 / 目标值 |

播报设置项：启用开关、播报间隔（0.01% / 0.05% / 0.1% / 0.5% / 1% / 5%）、字号、颜色、停留时间（1–10 秒）、垂直偏移、自定义鼓励语（用 `;` 分隔，留空用内置）、音效开关（**拾取金币音效**）。

想先看看效果：设置面板里点「测试播报」，或聊天框输入 **`/gttx test`**。

> 说明：为了避免刷屏，一次跨过多个台阶（比如拍卖行一次结算几千金）**只播报一次**。

### 大里程碑（10% / 25% / 33% / 50% / 75% / 90%）

跨过这些节点时，用**专属鼓励语**播报，字号放大到 1.25 倍，颜色也单独设置（默认更亮的金色）。例如：

- 10%：`开门红！已完成 10%，稳稳起步`
- 50%：`半程达成！说好的坚持你做到了`
- 90%：`90%！最后一段路，稳住就赢了`

没跨过这些节点就用普通鼓励语。可在设置里关掉，测试用 **`/gttx test big`**。

### 花钱惋惜提示

金币**减少**时会播一句惋惜（默认不响金币音，太扎心，需要可在设置里打开）：

| 情况 | 提示 |
| --- | --- |
| 一次花掉 ≥ 目标的 0.01%（约 700 金），或花掉持有金币的 ≥ 1% | 随机惋惜语（**20 条普通 + 10 条网络梗**，共 30 条） |
| 一次花掉持有金币的 **1%** | `一次花掉 1% 家底，小场面` |
| 一次花掉 **10%** | `十分之一没了，肉疼指数 +1` |
| 一次花掉 **50%** | `一半家当没了，这波有点狠` / `50%！钱包直接腰斩` |
| 一次花掉 **99%** | `几乎清空了……从头再来吧` |

惋惜文本默认 `{praise}，本次花掉 {spend} 金币，进度回到 {pct}`，可在设置里改（占位符：`{praise}`、`{spend}`、`{pct}`、`{remain}`、`{cur}`、`{goal}`）。测试用 **`/gttx test regret`**。

> 阈值可调（0.01% / 0.05% / 0.1% / 0.5% / 1% / 5%），不想要就在设置里关掉。

## 四、日常操作

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 移动显示框（锁定后按住 **Alt** 再拖） |
| 右键点显示框 | 打开设置（默认**关闭**，需在设置里勾选「右键点进度文字打开设置」） |
| 鼠标悬停 | 查看账号金币明细 |
| `Ctrl + 滚轮`（指针停在框上） | 调整大小 |

### 设置窗体（原生窗口）

设置现在是**独立的原生窗体**（暴雪标准对话框外观：系统背景/边框、标题栏、可拖动、右上角 X、**ESC 关闭**），不再塞进插件列表面板里。

打开方式：输入 `/gttx` / ESC → 选项 → 插件 → GoalTracker → 点「打开 GoalTracker 设置」。

> 右键点屏幕上的进度文字**默认不再弹设置**（避免误触）。想要的话：设置 → 位置与拖动 → 勾选「右键点进度文字打开设置」。

底部两个按钮：

| 按钮 | 行为 |
| --- | --- |
| **保存** | 保留本次改动并关闭，聊天框提示「设置已保存」 |
| **关闭** | 放弃本次改动并关闭，恢复到打开前的状态；右上角 X 和 ESC 同样是「放弃」 |

> 所有改动都是**即时生效**的（方便你边调边看屏幕上的效果），所以「保存 / 关闭」决定的是最后要不要留下这些改动。

### 命令

```
/gttx              打开设置（默认命令；被占用时自动用下面这些）
/gt /goal          备用别名
/goaltracker       保底命令，一定可用
<命令> lock        锁定 / 解锁位置
<命令> reset       框体回到屏幕中央
<命令> gold        聊天框打印账号金币明细
<命令> test        测试里程碑播报
<命令> test big    测试大里程碑（50%）
<命令> test regret 测试花钱惋惜提示
<命令> cmds        查看当前真正生效的命令
<命令> cmd gtx     把命令改成 /gtx（立即生效，不用重载）
<命令> dump        打印角色快照原表，排查「登出没记录」
<命令> help        命令帮助
```

**和别的插件抢 `/gt` 怎么办（v2.1 已自动处理）**

插件启动时会检查 `/gt`、`/goal` 是否已被别的插件占用：

- 被占用 → **自动让出**，改用 `/goal`、`/goaltracker`，并在聊天框提示一次：
  `GoalTracker: /gt 已被其它插件占用，已自动改用：/goal /goaltracker`
- 登录后 3 秒会再复查一次（部分插件进入世界后才注册命令），能补回就补回。
- 想自己指定：设置面板 → **聊天命令** → 填 `gtx`，或聊天框输 `/goaltracker cmd gtx`，立即生效。
- 确定要让 GoalTracker 接管 `/gt`：勾选 **强行占用 /gt**（需 `/reload`）。
- 完全不打印提示也不影响：只要 `/goaltracker` 一定可用。

也可以走：ESC → 选项 → 插件 → GoalTracker。

## 五、设置项速查

**目标**
- 目标类型：金币（战网账号合计）/ 物品装备 / 任务 / 声望 / 货币 / 自定义数值 —— 金币为默认，其它类型只是备用，播报逻辑对它们同样生效。
- 目标名称：填了显示你的文字，留空显示「战网金币」。
- 金币目标：单位"金"，默认 `7000000`。
- 统计范围：全部角色 + 战团银行 / 仅当前角色。
- 显示文本格式：`{name} {cur} {goal} {pct} {remain} {status}`，默认 `{name}  {cur} / {goal}  ({pct})`。

**外观**：字体（客户端全部内置字体，装了 SharedMedia 会额外列出）、字号 8–64、描边 无/细/粗、文字颜色（12 色预设 + 调色板）、完成颜色、阴影。

**里程碑播报**：见上一节。

**位置**：锁定位置、鼠标穿透、整体缩放、图层层级、重置位置。

## 六、文件结构

```
GoalTracker/
├─ GoalTracker.toc    描述文件（Interface 版本号、SavedVariables 声明）
├─ Locales.lua        中英文文本 + 内置鼓励语库
├─ Core.lua           账号金币统计、进度计算、里程碑判定、事件
├─ Display.lua        显示框体、拖拽、播报动画
└─ Options.lua        设置面板
```

无任何外部库依赖。设置使用 **账号级** SavedVariables（`GoalTrackerDB`），整个战网账号下所有角色共用同一个 700 万目标与进度。

## 七、常见问题

**Q：为什么某个角色的金币没算进去？**
A：那个角色还没登录过。用它登录一次（插件会自动记录），或设置面板点「刷新」确认当前角色已记录。

**Q：战团银行的钱显示 0？**
A：打开一次战团银行就会刷新到正确数值。数据未加载时接口会返回 0，插件不会用 0 覆盖已有记录。

**Q：播报一直不出现？**
A：确认「启用播报」已勾选；默认每 700 金（0.01%）触发一次，金币增长没到 700 就不会触发。可以先点「测试播报」确认画面正常。

**Q：播报太频繁 / 太少？**
A：改「播报间隔」，0.01% → 0.05% / 0.1% / 1% 等。

**Q：拖不动框体？**
A：检查是否勾选了「锁定位置」（锁定后需按住 Alt 拖）或「鼠标穿透」（完全不响应鼠标，此时用 `/gt` 开设置）。

**Q：框体不见了？**
A：`/gttx reset` 回到屏幕中央（命令被占用时换成 `/goaltracker reset`）。

**Q：报错 `bad argument #1 to 'SetFrameStrata'`？**
A：12.0.x 客户端不再接受 `HIGHEST` 这类旧层级名。v2.1.1 起改为逐级降级（`HIGHEST → FULLSCREEN_DIALOG → DIALOG → HIGH → MEDIUM`），并对 backdrop / 动画接口做了保护，不会再因为单个接口变动导致整个插件报错。

**Q：报错 `bad argument #1 to 'concat' (table expected, got nil)`？**
A：v2.1.1 的面板「聊天命令」一处引用了后面才声明的局部变量（Lua 下会读到全局 nil）。v2.1.2 已修正声明位置，并加了静态检查防止再犯。

## 九、构建与发布

仓库已带 CurseForge 打包描述文件 `.pkgmeta`，并配了 GitHub Actions（`.github/workflows/release.yml`）。

**自动出包**：打 tag 并推送即触发

```
git tag v1.0.1
git push origin v1.0.1
```

工作流会用 BigWigs 官方打包器按 `.pkgmeta` 生成 `GoalTracker.zip`（排除 `.git` / `.github` 等开发文件，并自动附带 `LICENSE.txt`），作为 artifact 和 Release 附件。

**投到 CurseForge / Wago**：两步

1. 把 CurseForge 的 **Project ID** 写进 `GoalTracker.toc`（项目页面右侧「About Project」方框里的数字）：

   ```
   ## X-Curse-Project-ID: 123456
   ```

2. 在仓库 Settings → Secrets and variables → Actions 里添加
   `CF_API_TOKEN`（CurseForge，注意是 TOKEN 不是 KEY）或 `WAGO_API_TOKEN`（Wago）。
   出包后会自动投递，不配置则只在本仓库出包。

**手动发布**：把插件目录 `GoalTracker/` 直接压缩成 zip，确保 zip 内是单层 `GoalTracker/` 目录（不要带版本号在文件夹名里），到 authors.curseforge.com 上传即可。
